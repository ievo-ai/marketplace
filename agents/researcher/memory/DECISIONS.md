# DECISIONS

## D-001: Research Methodology
- Search arXiv, engineering blogs, GitHub trending, HN
- Focus on last 2-4 weeks for news, any time for foundational concepts
- Applicability threshold: >= 3/5
- Maximum 5 proposals per session
- Always link primary sources

## D-002: Proposal Format
- Use PROP-{date}-{slug}.md in spec/research/
- Include scores, affected components, concrete proposed changes
- No vague suggestions — every proposal must be actionable
